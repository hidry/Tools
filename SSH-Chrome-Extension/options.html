⚙️ SSH Manager – Einstellungen

Konfiguriere die Verbindung zur lokalen SSH-Bridge.

Bridge-Verbindung

Standard: ws://localhost:2222 — der Docker-Container muss laufen.

SSH-Bridge starten

Die SSH-Bridge läuft als Docker-Container. Einmalig starten mit:

cd ssh-bridge && docker compose up -d

Danach ist die Bridge unter ws://localhost:2222 erreichbar und bleibt beim Systemstart aktiv (restart: unless-stopped).
